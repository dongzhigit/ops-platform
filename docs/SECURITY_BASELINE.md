# M0 安全验证基线

验证日期：2026-08-18

## 当前结论

M0 过渡镜像已经可以重复构建，但尚不满足正式生产发布条件。它可用于隔离内网中的兼容性验证，不应直接暴露到公网。

Trivy 0.65.0 对 `spug-ops:0.1.0-alpha.10` 的严重和高危漏洞复扫结果如下。数量是漏洞在软件包中的出现次数，并非去重后的 CVE 数量；漏洞库更新后数字可能变化。“有修复版本”指 Trivy 状态为 `fixed` 且给出了修复版本的项目。

| 层级 | 严重 | 高危 | 有修复版本 |
| --- | ---: | ---: | ---: |
| CentOS 7.9.2009 | 0 | 155 | 46 |
| Python 依赖 | 3 | 48 | 51 |
| 合计 | 3 | 203 | 97 |

Dockerfile 纳入 CentOS 7 最终安全更新后，操作系统层严重漏洞降为 0。`0.1.0-alpha.9` 最终镜像因保留 Git 等发布流程必需工具，操作系统层为 155 个高危；CentOS 7 已停止安全维护，扫描器也明确提示检测结果可能不完整，因此这些更新只是过渡措施。漏洞库更新会导致统计数字和可修复判定变化，本表使用 Trivy 0.65.0 在 2026-08-18 下载的最新数据库复扫。

尚存的严重项：

| CVE | 组件 | 当前版本 | 修复版本 |
| --- | --- | --- | --- |
| CVE-2025-64459 | Django | 2.2.28 | 4.2.26 / 5.1.14 / 5.2.8 |
| CVE-2022-24439 | GitPython | 3.0.8 | 3.1.30 |
| CVE-2023-40267 | GitPython | 3.0.8 | 3.1.32 |

这些版本无法在当前 Python 3.6 技术栈中安全原地升级，必须通过 Python、Django 和相关 Channels 依赖的升级分支统一解决。

## 可观测性辅助镜像扫描

alpha.10 在固定旧版本的初次扫描中发现 Go 运行时严重漏洞，因此发布配置已升级到扫描时官方可用的最新固定版本。最终纳入默认 Compose 的结果如下：

| 镜像 | 严重 | 高危 | 有修复版本 | 结论 |
| --- | ---: | ---: | ---: | --- |
| `prom/prometheus:v3.14.0` | 0 | 0 | 0 | 本次门禁通过 |
| `prom/alertmanager:v0.34.0` | 0 | 0 | 0 | 本次门禁通过 |
| `prom/node-exporter:v1.12.1` | 0 | 8 | 8 | 官方最新镜像仍使用 Go 1.26.5，需等待或重建为 1.26.6+ |

评估过但未纳入部署栈的 `prom/blackbox-exporter:v0.28.0` 为 2 个严重、36 个高危，38 项均有修复版本。它同时命中 Go TLS 漏洞和 gRPC 授权绕过，且当前功能并未使用该组件，因此没有让一个闲置且已知脆弱的服务随默认 Compose 启动；站点、端口和 Ping 继续使用现有兼容探测器。

## Guacamole 辅助镜像扫描

RDP/VNC 使用的官方镜像也不满足正式生产门禁：

| 镜像 | 扫描范围 | 严重 | 高危 | 备注 |
| --- | --- | ---: | ---: | --- |
| `guacamole/guacamole:1.6.0` | Ubuntu 24.04 OS 包 | 0 | 11 | 11 项均有修复版本 |
| `guacamole/guacd:1.6.0` | Alpine 3.18 OS 包 | 0 | 0 | Alpine 3.18 已停止安全维护，检测可能不完整 |

Guacamole Web 的 Java 依赖扫描需要额外下载约 908 MiB 的 Trivy Java 漏洞库；本次下载在当前网络下无法在可重复门禁时间内完成，因此 Java 依赖结果明确记为“未验证”，不能把上表解读为 Guacamole Web 只有 11 个高危。正式生产前必须在 CI 缓存 Java DB 后完成扫描，并升级或重建存在可修复高危包的镜像；guacd 也必须迁移到仍受支持的基础系统。

## 正式发布门禁

- 严重漏洞必须为 0。
- 有可用修复版本的高危漏洞必须修复；不能立即修复的项目需要有负责人、影响分析、隔离措施和到期时间。
- 基础镜像、Python 和 Django 必须处于官方安全支持周期。
- 依赖版本必须锁定，镜像必须在 CI 中重新构建和扫描。
- 数据库备份恢复、迁移回滚、Linux FUSE 文件分发和 TLS 反向代理必须在目标环境完成演练。

复扫示例：

```bash
trivy image --scanners vuln --severity CRITICAL,HIGH spug-ops:0.1.0-alpha.10
```
